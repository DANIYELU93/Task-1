# Fashion One – Responsive Landing Page

Fashion One is a simple and modern **fashion-tech landing page** built using HTML5 and CSS3. It combines fashion, style, and technology with a clean **light green and white** color palette.

## 🎯 Project Objective

The goal of this project is to create a responsive landing page while practicing basic web development concepts such as Flexbox, CSS Grid, and Media Queries.

## 🛠️ Technologies Used

- HTML5
- CSS3


## 👗 Services

### Smart Styling
Find styles that match your personality and everyday look.

### Latest Trends
Explore new fashion trends and discover fresh ideas for your wardrobe.

### Virtual Fashion
Experience fashion in new ways with modern digital technology.

## 📱 Responsive Design

The website adapts to different screen sizes using CSS Media Queries.

- Desktop
- Tablet
- Mobile

Flexbox is used for navigation and alignment, while CSS Grid is used for the services section.
